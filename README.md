# SIEM Homelab Project

This repository documents a comprehensive Security Information and Event Management (SIEM) homelab project, demonstrating enterprise-level security monitoring capabilities using open-source tools.

The project covers the full lifecycle of a SIEM deployment, from virtual machine setup and core component installation to agent deployment, attack simulation, and threat detection analysis.

## Repository Structure

| Directory | Content |
| :--- | :--- |
| `Documentation/` | In-depth documentation of the project phases, including setup, configuration, and analysis. |
| `Assets/Screenshots/` | **All visual evidence (screenshots) of the project steps and results.** |
| `Code/` | Configuration files and scripts used for the Wazuh manager and agents. |

## Project Phases

1.  **Virtual Machine Setup:** Configuration of the virtual environment for the Wazuh Manager and Kali Linux Agent.
2.  **Wazuh Manager Installation:** Step-by-step installation and initial configuration of the Wazuh SIEM platform.
3.  **Agent Deployment:** Deployment and enrollment of the Wazuh Agent on the Kali Linux endpoint.
4.  **Security Monitoring and Alerting:** Simulation of attacks (e.g., Nmap scans) and analysis of the resulting security alerts and threat hunting data in the Wazuh Dashboard.

## Evidence

All screenshots are organized and consistently named to provide clear, chronological evidence of the project's execution. They are located in the `Assets/Screenshots/` directory.
